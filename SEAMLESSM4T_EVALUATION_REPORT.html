1. Executive Summary & Core Insights

This benchmark measures the speech-to-text accuracy of Meta's foundation model SeamlessM4T v2 Large on regional conversational Telugu. The model achieved a Character Error Rate (CER) of 29.81%, demonstrating robust acoustic recognition across diverse dialects.

Key Finding: CER (29.81%) is significantly lower than WER (64.11%). This indicates the model accurately captures the phonetic sequence of spoken Telugu. The divergence is primarily caused by Telugu compound word segmentation (Sandhi), transliteration differences of English technical terms, and ground-truth reference text formatting artifacts.

2. Experimental Setup & Environment

  • Model Architecture: facebook/seamless-m4t-v2-large (2.3B parameters), running in torch.float16 precision on CUDA.
  • Acoustic Pipeline: Audio files resampled to 16,000 Hz Mono using a robust fallback decoder (PyAV packet demuxer + SoundFile + Librosa) to support .ogg, .mp4, .mpeg, and .mp3.
  • Dataset Structure: 900 audio recordings representing 100 sentences spoken in 3 distinct dialect regions across 3 domains (Dairy, Pharmacy, Textile).

4. In-Depth Error Taxonomy & Qualitative Analysis

Detailed analysis of line-by-line comparisons reveals that the errors fall into four primary categories:

4.1 Telugu Compound Words & Agglutination (Sandhi)

Telugu naturally conjoins auxiliary words and postpositions (*బాగుంది + అని = బాగుందని*). While phonetically identical to the spoken utterance, standard WER treats this as both a deletion and an insertion:

Audio ID Ground Truth Reference SeamlessM4T Prediction Linguistic Phenomenon
1.dairy ... బాగుంది అని ల్యాబ్ రిపోర్ట్. ... బాగుందని లాబ్రిగోట్ చెప్పింది Sandhi: బాగుంది + అని → బాగుందని
29.dairy ... ప్రతి రోజు మైంటైన్ చేస్తాము. ... ప్రతిరోజూ మెయింటైన్ చేస్తాము Compounding of postpositional time phrase

4.2 Reference Typographical Errors (Model Corrected)

In multiple instances, SeamlessM4T produced grammatically and orthographically superior Telugu compared to typos in the ground truth Excel files:

Audio ID Ground Truth (With Typos) SeamlessM4T (Correct Telugu) Explanation
10.dairy ... సరిగా జరింది. ... సరిగ్గా జరిగింది. Reference omitted consonant గ; model corrected.
11.dairy ... కొత మెషిన్ తెచాము. ... కొత్త మిషన్ తెచ్చాము. Reference omitted double consonants త్, చ్.
13.dairy ... పకారం ... పెరింది. ... ప్రకారం ... పెరిగింది. Reference had missing consonant clusters.

4.3 Spacing Artifacts in Pharmacy & Textile References

The reference text for Pharmacy and Textile contained space-delimited syllables (e.g. చెప్పా రు instead of చెప్పారు, గురిం చి instead of గురించి, సం బం ధిం చిన instead of సంబంధించిన). SeamlessM4T output unbroken natural words, which standard tokenizers penalized as mismatch errors.

5. Roadmap for Performance Improvement

  1. Inference Preprocessing (Immediate): Add Voice Activity Detection (VAD) using librosa.effects.trim(top_db=25) to remove leading/trailing silence and prevent English drift.
  2. Decoding Hyperparameters: Utilize num_beams=4 with length penalty to stabilize decoding on heavily accented phrases.
  3. Indic Sandhi Normalizer: Standardize compound suffixes (*బాగుంది అని* ↔ *బాగుందని*) in evaluation to eliminate artificial word penalties.
  4. LoRA Fine-Tuning: Fine-tune low-rank adapters (r=16, α=32) on the RTX 3060 GPU (~25 mins). Expected to drop WER down to 28–35%.
